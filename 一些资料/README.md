# 一些资料

这里保存截至 2026 年 10 月 16 日整理的需求修订、产品材料、架构分析和开发验证记录，便于后续阅读、维护和继续开发。

`01-需求与基线` 包含归档时的需求基线、两份需求导入表，以及尚未合并回正文的协作备忘修订；其中平台数据网关需求基线和跨服务协作备忘包含归档前的本地修改。

`02-产品材料` 包含产品介绍、白皮书、演示文稿、演示视频、字幕和材料生成脚本。`03-架构与源码分析` 保留架构页面、图示及源码分析，HTML 页面可下载后在浏览器中打开。

`04-开发与测试文档` 保存实现说明、接口约定、阶段记录和验证报告。`05-界面验证记录` 保存页面截图、浏览器快照与检查结果。`06-历史验证与辅助脚本` 保存本地验证过程中的脚本和文字结果，`07-早期文档快照` 保存早期版本中具有不同内容的文档。

记录中的运行结果属于各文件标注的历史测试环境。脚本中的本机目录已替换成示例路径，凭据已替换成占位内容；再次运行时需要按照当前环境配置目录、依赖和凭据。正式代码与发布包请从仓库根目录及 Releases 获取。

`文件清单.json` 记录归档文件的原相对路径、大小、SHA-256 和脱敏状态，可以用来定位原目录及校验下载内容。Office 文件已清理作者属性，工作表、文档和幻灯片正文保持原有内容。
