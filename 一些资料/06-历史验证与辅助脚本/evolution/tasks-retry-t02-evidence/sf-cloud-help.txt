Usage of /private/tmp/smartfactory-t02-current/sf-cloud:
  -config-url string
    	independent configuration center URL
  -database string
    	PostgreSQL URL or SQLite development file (default ".local/cloud.db")
  -datatransfer string
    	local DataTransfer gRPC address
  -listen string
    	HTTP listen address (default "127.0.0.1:8090")
  -master-key string
    	encryption and audit signing key file (default ".local/cloud.key")
  -node-id string
    	registered node identifier (default "cloud-1")
  -seed
    	load the editable simulation factory
  -static string
    	offline frontend directory (default "../Frontends/dist")
