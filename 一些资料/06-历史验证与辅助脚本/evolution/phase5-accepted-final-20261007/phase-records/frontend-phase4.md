# 查询、参数编辑与业务处理页面

云端控制台从 `index.html` 进入，现场工作台从 `edge.html` 进入，运行大屏从 `screen.html` 进入。第四阶段增加协议与设备参数、告警处置、工单与交接、场景模板，以及保存实际依据的 AI 调查；草稿编辑器提供节点元数据表单、语义差异和影响结果。现有审批与执行、历史分析、后台任务和运行状态页面继续使用统一契约客户端。

设备、告警、趋势和执行列表采用服务端筛选与分页。更换资源、筛选条件或页面时，查询按新的范围取得结果；实时推送显示订阅状态，断网后显示等待网络恢复，并按最后成功应用的游标恢复。服务端要求重新取得快照时，页面清空失效结果和旧分页位置。退出登录、会话失效或资源授权变化后，旧身份的缓存和临时编辑状态清除，页面按当前身份重新读取。

“协议与设备参数”根据协议目录展示连接、设备地址、采样、数据点和动作映射。每个字段显示类型对应的控件、单位、必填条件、枚举、范围及说明；完整参数窗口用于调整目录之外允许保留的扩展。Modbus TCP、MQTT 设备和 OPC-UA 的字段与校验采用各自元数据，配置预检显示服务端返回的问题路径。云端和现场的保存条件按对象归属与允许操作显示，正式连接器列表同时展示配置版本、确认版本和下发状态。

参数保存的操作流程如下。

1. 按显示名称选择设备，打开基础参数窗口，核对已阅版本、协议及操作条件
2. 在元数据表单中修改字段；需要保留精确整数或扩展对象时，打开“完整参数与扩展”并输入有效 JSON
3. 执行配置预检，查看字段路径与问题说明，通过后保存参数；服务端返回的新版本可以再次打开核对
4. 遇到版本冲突时查看最新状态，使用“采用更新后的保存依据，保留已填写参数”，核对后再次提交

节点参数表单采用规则节点目录，显示输入、输出端口及其类型。基础字段覆盖数值、整数、文本、JSON、布尔值和枚举，应用时检查必填与范围；完整参数窗口保留未知扩展。完整 JSON 修正已有字段或删除数据点后，对应的旧错误会清除，不同章节中同名字段分别维护校验状态。JSON 整数 `9007199254740993` 与文本 `"9007199254740993"` 在往返编辑中保持各自类型。

草稿编辑与服务端列表更新分别维护。切换页面再返回时，当前账号尚未提交的名称、画布、节点和完整参数继续显示；后台更新草稿目录时也保留当前编辑。保存发生版本冲突后，可以明确更新保存依据并继续提交。语义差异窗口显示比较的草稿和正式版本、节点与连线变化、参数及端口类型，以及受影响的规则、设备、依赖和输出；带身份的条目可以打开对应对象。

告警处置工作台显示异常周期、人员确认、责任人、处置状态和当前原生同步结果。打开操作窗口时，页面保存操作者已经查看的人工版本和 `action_version`，持续观测更新列表时继续采用这份依据。条件变化导致冲突后，理由和已阅版本继续保留，操作者查看新状态并明确采用新依据后重新提交。允许操作及禁止原因由服务端返回；没有完成条件的告警会禁用完成按钮。

工单页面支持创建、开始处理、分配、变更、备注、完成、重新打开和交接。交接记录保存新的责任人、未完成事项、人工理由，以及操作者选中的告警或执行依据版本；告警依据同时包含人工处置版本。交接完成后，原责任人和新责任人的按钮按当前允许操作更新，处理过程与交接记录可在详情中核对。

“场景模板”提供温湿度与通风、红外照明、危气监测、AGV 避障及货物计数。页面按协议、必需数据点、动作能力、设备归属和正式配置筛选可用绑定，批次固定设备版本、配置身份和配置版本。准备结果显示生成的草稿及问题；冲突批次保留失败结果与尝试记录，外部条件处理后可以重试原批次。

AI 调查每次发送保存独立调查，页面显示运行状态、实际工具调用、最终答案及逐条引用状态。依据抽屉显示进入模型的 JSON 原文、工具调用身份、调用参数、原文字节预算、SHA256 和当时读取的资源版本；中文、斜杠和冒号身份经过完整路径转义后导航。工具失败、空查询、预算超限、未知引用、跨调查引用和未引用依据的回答分别显示对应状态，连接中断后读取已保存的终止状态。

调查和依据按当前权限及原始资源检查可访问性。撤权、过期、资源删除或调查内容删除后，页面清除已失效的答案、原文、参数与资源；已经打开的依据抽屉也根据调查轮询结果立即隐藏旧内容。再次取得依据时，403、404、410 显示当前原因，401 清除会话并返回登录页。其他账号无法读取前一账号的调查，也不会继续显示其尚未提交的草稿编辑。

三个入口采用 ECharts 6.1.0，折线、布尔状态轴、单位图例、数据修订和告警标记使用统一封装。横轴采用 Asia/Shanghai 时间并隐藏重叠标签，超大或极小数值的坐标轴使用科学计数格式；坐标用于展示近似位置。工具提示、精确记录表和完整 JSON 导出保留原值、质量、来源、单位及修订，支持有符号整数、无符号整数、浮点数、数字文本、布尔值和聚合对象。历史导出逐页取得固定范围，大屏可以打开指标详情并导出精确数据。
