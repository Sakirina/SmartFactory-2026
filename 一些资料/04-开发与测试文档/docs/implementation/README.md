# SmartFactory 实施与交付入口

SmartFactory 将工厂设备采集、现场联动、数据分析和业务审批组织在同一套云边系统中。当前仓库包含 DataTransfer、Go 云端与边缘业务服务、独立配置中心，以及云端控制台、现场页面和管理大屏。三套页面共享接口、图表和编排组件，现场页面的静态文件随程序交付。

实施依据为 2026 年 9 月 20 日确认的完整交付计划；开发与测试过程中追加了批量写入、内存测试环境和完整原始数据压缩归档。30 天原始保留期继续采用计划中的默认值，最近 24 小时保留热数据，其余按设备和字段归档，查询与补算自动读取两类数据。

## 当前可复现内容

五个场景通过实际 Modbus、MQTT 和 OPC-UA 模拟设备完成采集与控制，控制后的设备状态可从业务 API 查询。货物场景完成额外 10000 个有效事件的重复投递、网关重启与断连恢复检查；云端和边缘最终计数均为 20100，与原有 10100 个事件和新增事件相符。

DataTransfer 的 500 台设备测试持续 3600 秒，共产生并保存 18654020 条单测点消息，平均 5181.65 条/秒，输入与保存计数一致；最大 RSS 为 61,341,696 字节，1000 次控制的 p99 为 18.584 毫秒。该记录对应采集程序与独立验收记录器，使用当时构建的二进制，SHA-256 保存在报告中。

业务层在 PostgreSQL 内存测试环境中完成 20 个 SSE 订阅和 10 个并发历史查询的 180 秒测量，包含 30 天原始数据样本、三年日汇总与压缩归档。历史查询 p95 为 1.564 秒，SSE 首次收到新观测的 p95 为 1.096 秒；20 个独立浏览器会话的实际显示延迟 p95 为 798 毫秒。页面功能检查覆盖三种尺寸、精确整数、草稿编辑、大屏保存与页面助手。

三节点、150 台 MQTT 5.0 设备完成 100 次故障注入，包含单副本退出、协调者退出、参与者退出和多数分区，重复物理动作数为 0。测试持续 1333.94 秒，设备状态和降级结果逐轮保存在机器可读报告中。

## 环境与版本

ThingsBoard CE 固定为 `v4.3.1.5`，源码提交 `2cd31ac359214f94b945546830da503ddf80070f`；Edge 固定为 `4.3.1.1EDGE`，源码提交 `04d9daf4a557a13483de2310e35b6493aff751fc`。镜像清单、平台和内容摘要保存在 `deploy/images.lock.json`，源码版本保存在 `deploy/dependencies.json`。自研代码与生成的接口类型保存在本仓库。

本次测量环境为 macOS arm64；PostgreSQL、ThingsBoard 和 NATS 通过已获取的 Linux 镜像运行。大批量功能、查询和归档测试使用内存数据库或有容量限制的 tmpfs。持久提交、断电语义和恢复检查使用明确的数据规模，输出实际存储方式。

UOS Server V20 x86_64 虚拟机尚未创建。A01 国产系统部署、A08 连续断云 24 小时及六小时恢复、A09 连续断云 24 小时、A12 实际 24 小时存储测量仍需在目标环境执行，完整验收以这些项目通过为条件。
