# 开源基础与自研内容声明函草稿

项目名称：SmartFactory 工厂监测与现场联动平台。

参赛单位、团队成员与指导教师由参赛者在提交前填写，签署日期以实际签署时间为准。

本项目采用 ThingsBoard CE v4.3.1.5、ThingsBoard Edge 4.3.1.1EDGE 及项目组件清单所列的开源依赖。固定源码版本、镜像摘要和依赖版本随提交包提供，上游源码与许可证信息保存在相应组件目录及许可证清单中。

项目自行开发和扩展的内容包括 DataTransfer 的协议采集、消息确认和设备控制能力，Go 云端与边缘业务服务，独立配置中心，三套业务前端，以及公共契约、协议模拟器和验收工具。业务实现覆盖组织与资源授权、编排草稿与发布、历史修订、控制会签、现场协调、可校验审计和 AI/MCP 查询及草稿操作。

本声明所对应的提交版本以交付包中的 release-manifest.json 为准，文件摘要记录该次实际提交内容。测试报告分别记载已经执行的项目、运行环境、数据规模与尚待完成的验收；产品介绍和演示视频中的功能、性能陈述以对应证据为依据。

参赛者在提交前核对团队署名、各组件的许可证及署名要求、上游修改说明和赛事最新材料要求，并完成学校或发榜单位要求的签字手续。
