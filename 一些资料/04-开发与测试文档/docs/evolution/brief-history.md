历史计算工程师任务说明

本任务在第二阶段规则计算与后台任务接口验收后启动，负责 E3-04 至 E3-06，以及 E3-07 的节点计算解释。负责人使用第二阶段已经形成的编译计划、确定性计算帧和后台任务接口完成历史回放、版本效果比较与影子计算；控制执行和页面交互分别由其他专家角色负责。

实施前读取当前 [验收清单](acceptance.json)、`rules-frontend-contract.md`、`tasks-frontend-contract.md` 和规则、存储工程师的最终报告。现有 `engine/history.go` 的 `Recompute` 会按历史输入补算，并在完成时替换正式状态、修订告警和生成后续投影。新增历史分析运行具有自己的运行身份、输入快照、规则及资产版本、结果和状态，入口及保存方式需要满足其分析用途。

历史回放按指定时间和输入序列选择当时的规则与资产版本，保留观测的来源、单位、质量、设备时间和迟到或修订信息。请求和结果能够核对采用的输入排序、初始状态、逻辑时钟、计划身份、历史快照及其内容摘要。跨越规则和资产版本变化时，运行记录应显示具体采用的版本及生效时间；范围内原始数据缺失、数量超出预算或计划无法准备时给出可操作的状态与原因。

版本比较为同一组明确输入、初始状态和时钟分别使用两个明确规则版本，保存两侧计划身份及独立结果，再比较数值、质量、告警判断、状态和节点路径的变化。比较记录引用已经保存的输入与运行结果，避免页面分别查询时取得不同数据。资源授权覆盖两个版本的全部引用、输入、历史和资产版本，查询运行结果时再次检查访问范围。

影子计算以已确认的候选规则跟随规定实时输入，候选启用、停止和替换具有版本及审计记录。输入传播及结果保存按观测身份和修订实现幂等，保存影子运行的游标、状态及与正式输出的比较关系；进程中断后可以按既定游标继续。候选计算产生的状态、告警判断及动作意图保存在自己的结果中，测试应核对正式状态、告警、后续投影和设备动作记录的完整性。

验证流程如下：

1. 使用跨规则版本、资产归属变更、乱序及补传的有限样本验证历史回放，逐条核对来源、单位、质量和版本，并检查分析运行的状态隔离与结果查询权限
2. 使用结果发生变化和保持一致的规则版本验证比较，核对同一输入摘要、时钟、初始状态及两侧计划身份，覆盖精确整数与历史窗口
3. 使用实际观测入口驱动影子计算，验证重复和修订观测、候选启停、进程恢复、结果去重及正式业务状态和动作次数
4. 为长任务接入现有后台任务调度和预算，验证取消、失败、重试与查询；提供节点计算过程与来源关联 API，将字段、状态和示例写入 `history-frontend-contract.md`
5. 保存实际命令、输入快照摘要、数据库检查、测试结果与受测文件摘要，形成 `.local/evolution/history-analysis-verified.json`，交给前端工程师完成页面验证并交回主协调者验收

文件归属包括历史分析应用用例、隔离运行模型与存储调用、影子输入订阅、相关 API 和计算解释；对 `engine/history.go`、`runtime.go`、后台任务注册及共享模型的修改先与对应负责人协调。计算算子继续采用第二阶段统一规则核，新增持久结构沿用编号迁移和契约生成约定。

计算路径沿用OpenTelemetry基础，将实时计算及历史运行的消息、计划、定义版本和运行身份关联到追踪，节点解释记录与实际输入和输出相对应；操作名及指标标签使用有限类别。专项验证包含后台计算与存储事务的关联，规则参数和完整原始观测按现有数据权限查询。

第二阶段已交付实际使用的领域存储接口，见 `application/repositories.go` 与 `tasks/repository.go`。本阶段新增和改造的应用路径也应持有所需的存储接口，把驱动选择和SQL操作保留在存储实现；接口需用于生产调用。共享修改采用明确归属：新增模型优先放在本角色独立文件；现有Execution结构及控制注册由控制专家维护，独立分析模型及历史任务注册由历史专家维护。API总注册、app.go、Go模块、迁移注册和契约导出器的编辑时段由主协调者分配，新增持久迁移先申请当前下一编号并保留旧文件校验值。

当前补算实现还会使用rawRange扩展至保留期内可用的完整历史，并在finishReplay之前追赶新增观测；该行为服务于正式状态修订。新的独立分析应保存用户请求的明确范围及实际取得的输入快照，重试继续使用同一份快照。`engine/replay_checkpoint.go` 的recompute_run只固定范围、定义集合、设备与前置状态，输入仍通过Query读取；独立回放、比较两侧和影子修订需要按各自要求记录输入版本、摘要和使用结果，不能仅凭固定起止时间就宣称输入快照一致。
