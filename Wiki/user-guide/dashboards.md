# 管理大屏

[Wiki 首页](../README.md) · [数据监控](data.md)

管理大屏通过业务服务的 `/screen` 展示趋势、指标卡片、持续告警和来源。登录后选择已有配置，设备与字段按当前人员资源许可查询；完整部署通常使用云端 HTTPS 8443，本机演示使用 HTTP 8090。

## 创建与共享

1. 使用有大屏配置许可的账号选择“配置大屏”，填写名称与所属资产。
2. 选择趋势设备、测点、窗口和刷新方式；留空范围按当前账号可访问对象解析。
3. 添加指标卡片，指定设备、测点和显示名称，按需启用告警及来源面板。
4. 保存当前大屏，或另存为新配置，再核对实际趋势和卡片对应的对象。

指标可以采用原始测点或正式分析输出。工程师和管理员按授权维护配置，观察员读取已有配置；共享使用保存后的大屏身份，更新检查已阅版本，冲突时读取当前版本后继续编辑。

## 读数与状态

趋势使用指定窗口内的历史观测，卡片读取系列最新值并显示观测时间。布尔值采用阶梯显示，精确整数和复合值在文字与工具提示中保存原表示，坐标绘制采用显示数值。

来源面板展示最后通信和补传状态，告警面板展示当前持续周期。查询暂时失败时，页面显示错误及已有结果时间，人员可以重新查询；退出、会话失效或授权变化后清除受影响数据。

字段、质量与修订含义见[数据契约](../api/data-contract.md)，配置结构见 [Dashboard Schema](../../contracts/1.0/Dashboard.schema.json)。
