# 告警处置、工单交接与场景模板

[Wiki 首页](../README.md) · [五场景教程](../tutorials/five-scenes.md)

告警保存异常发生与恢复的周期，人员处置记录确认、责任人和处理状态；工单跟踪后续工作及交接。场景模板根据设备、正式连接器和参数建立可评审草稿，准备记录保留实际绑定及尝试结果。

## 告警处置流程

1. 在“告警处置”按设备、状态或责任人筛选，打开详情，核对异常周期、观测来源、人工处置版本和允许操作。
2. 阅读当前动作依据，填写理由，再确认、分配责任人或更新处置状态。
3. 出现冲突时保留理由，取得最新状态并更新已阅依据，检查动作含义后再次提交。
4. 处置后查看业务状态及原生 ThingsBoard 投影状态，核对两处结果和失败原因。

持续观测版本和人工处置版本分别保存。新采样仍维持相同动作含义时，已阅动作版本继续适用；恢复、级别变化或人工确认改变处置条件后，服务要求重新取得依据。

## 工单和交接流程

1. 在“工单与交接”创建工单，填写事项、关联告警或执行和责任人，打开详情查看当前状态。
2. 按 `allowed_actions` 分配、更新、补充备注、完成或重新打开，每次操作使用已阅业务版本。
3. 当前责任人或管理员选择交接，填写新的责任人、未完成事项与理由，选择已经阅读的告警或执行依据。
4. 提交后检查责任变化、人工请求、交接记录、依据版本与后续允许操作。

交接把责任更新、请求、证据和审计一同保存。告警依据含观测及人工处置版本，执行依据含设备步骤和实际反馈；原责任人、新责任人的可执行动作随当前状态重新计算。

## 场景模板

| 模板 | 绑定及业务内容 |
| --- | --- |
| 温湿度与通风 | Modbus TCP、温湿度、分析、告警和通风预案 |
| 红外照明 | MQTT、人员存在与照明动作 |
| 危气监测 | OPC UA、气体读数与排风动作 |
| AGV 避障 | Modbus TCP、距离、联锁与停车动作 |
| 货物计数 | MQTT、脉冲事件与累计统计 |

1. 在“场景模板”选择模板，阅读必需测点、动作能力和参数，选择可访问设备及正式连接器配置。
2. 核对设备归属、设备版本、配置身份和版本，填写实例名称及参数；带控制政策的模板指定符合条件的现场安全员。
3. 在云端准备含 1 至 20 个实例的批次，查看各实例问题和生成草稿；全部通过后，同批草稿及审计一起保存。
4. 失败时检查原批次尝试结果，修正外部条件后重试；需要改变输入或绑定版本时采用新的批次身份。
5. 对准备成功的草稿执行[校验与发布](definitions.md)，需要共同部署程序、规则和配置时继续[节点发布](node-releases.md)。

模板绑定检查协议、测点、动作映射、节点归属和正式配置。版本演进沿原批次与实例检查绑定和影响，生成新的固定组合及部署目标；正在填写的参数在后台刷新后继续保留，最终采用前核对本次版本及校验结果。
