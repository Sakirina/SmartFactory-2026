# 页面与导航

[Wiki 首页](../README.md) · [快速开始](../getting-started.md)

云端控制台用于集中维护设备、规则、人员和发布，现场工作台连接指定边缘节点，大屏使用业务服务的 `/screen` 展示授权范围内的运行情况。页面顶部和底部显示当前服务模式与节点身份，现场操作以所属节点的入口为依据。

## 选择入口和功能

| 入口或页面 | 使用场景 |
| --- | --- |
| 云端 `/` | 全厂查询、草稿评审、业务处置及管理 |
| 现场 `/edge` | 本节点准入、现场数据、执行确认与恢复 |
| 大屏 `/screen` | 趋势、最新指标、持续告警和来源状态 |
| 设备与资产、协议与设备参数 | 查看归属与准入，维护正式采集配置 |
| 数据分析、告警编排、联动预案 | 编写并评审相应定义 |
| 告警处置、工单与交接 | 处理异常周期与责任转移 |
| 历史补算、历史分析、后台任务 | 补算、回放、版本比较、任务进度与允许操作 |
| 云边发布、节点身份与配置 | 固定发布组合、逐批部署、身份授权和采用报告 |
| 组织与权限、配置中心、同步插件、业务审计 | 管理人员、程序参数、外部组织数据及审计 |
| AI 助手、通知记录、运行状态 | 调查依据、通知投递与节点及队列状态 |

云端根据角色显示定义和管理入口，现场提供本地业务功能；每次请求仍由服务端检查当前角色、资源及对象状态，操作窗口展示服务返回的允许动作和原因。相应指南都可以从[首页目录](../README.md)进入。

## 查询和刷新

顶部“页面刷新方式”提供实时推送、每秒刷新、每五秒刷新及手动查询，选择保存在当前浏览器。实时数据页使用固定筛选与时间范围，首屏订阅后接收变化；进入续页时按同一快照读取，需要取得新的时间窗口时再次点击查询。

页面显示最近更新、订阅状态或失败原因。临时查询失败后，可以读取已有结果的时间并使用“重新查询”；人员退出、会话失效或资源权限变化时，页面清除受影响查询内容，后续结果按当前身份重新取得。

对象详情支持设备、草稿、工单、执行、任务、调查与发布的导航链接。通过链接进入时查看页面中实际对象身份，随后从该对象继续阅读相关版本与依据；修改中的草稿、发布组合和操作理由由编辑状态保存，后台更新后继续保留当前填写内容。

## 日常检查流程

1. 在“运行概览”查看授权设备、告警、有效观测和等待投递数量，再核对来源最近通信时间。
2. 在“数据监控”选择设备、字段及时间，阅读质量、来源和修订，按需导出完整精确数据。
3. 打开异常对象的详情，通过[告警工单](business-workbench.md)、[控制](control.md)或[任务](history-tasks.md)指南处理当前允许动作。
4. 在“运行状态”检查队列和补传，管理人员按请求身份查阅审计；程序配置或发布问题继续[节点指南](node-releases.md)。

界面时间使用 `Asia/Shanghai`，API 时间使用 Unix 毫秒时间戳。完整部署和本机演示的端口由各自脚本记录，地址对应关系见[配置参考](../reference/configuration.md)。
