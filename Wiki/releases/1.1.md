# 1.1 版本说明

[Wiki 首页](../README.md) · [历史 1.0](1.0.md)

1.1 系列将草稿计算、持久任务、控制恢复、业务处置和节点发布组成完整操作流程。正式标签采用 v1.1.0 这类版本，main 快照采用 1.1.0-dev 加提交标识；实际应用版本、目标平台、源码及组件以取得归档的清单为依据，[发布页](https://github.com/Sakirina/SmartFactory-2026/releases)提供对应文件。

## 提供的能力

| 领域 | 1.1 行为 |
| --- | --- |
| 草稿与规则 | 统一应用许可、节点元数据、语义评审、发布编译、连续模拟与解释 |
| 数据与存储 | 精确值、服务端分页、可恢复订阅、归档、历史修订、编号迁移 |
| 持久任务 | River 作业、原任务身份、检查点、阶段、重试及取消 |
| 控制与历史 | 持久状态机、原命令核对、剩余步骤恢复、回放、同输入比较和影子候选 |
| 工厂业务 | 协议表单、告警周期与处置、工单及已阅交接依据、五类模板 |
| AI | 两种模型 API、实际工具依据、持久调查、引用权限与官方 MCP SDK |
| 节点与发布 | 独立工作负载、密钥引用、固定程序规则配置、首次转换、逐批运行与失败恢复 |
| 交付 | Linux amd64 包、三套页面、公开源码、契约、脚本、组件与许可来源 |

第一次使用见[快速开始](../getting-started.md)，首次工件登记和代理转换见[节点指南](../user-guide/node-releases.md)。发布再次采用旧内容时，固定来源与本地应用版本分别记录，数据库超出旧程序范围时使用配套备份流程。

## 已执行的验证

五阶段共 45 项功能验收已完成。1.1 开发组合的 Linux 正式包入口通过 55 项检查，包含独立 PostgreSQL 业务库、一个代理管理节点、正式 DataTransfer、首次转换、规则与配置往返、断开 cloud／config 后缓存启动、正常停止及原数据再次启动；独立双节点组合覆盖批次等待、阻断和恢复。

同一固定前端产物完成 39 项独立浏览器检查，涉及设备参数、草稿、告警、工单交接、模板、查询订阅、精确值、AI、首次发布、节点身份和两节点批次。控制、历史、任务与模拟页面采用各自已验收记录，并核对未变功能输入和当前受影响后端结果。

普通回归、实际 PostgreSQL 条件用例和限定 race 分别记录环境与范围。沿用结果时检查完整受测输入、编译选择和产物对应；共享调用变化后补验受影响普通、数据库、race、浏览器或包入口，原失败、跳过和后续结果分别保存。

协议与原生专项包含 OPC UA 签名加密、插件进程、MQTT、持久消息故障、云边 mTLS、NATS 三节点迁移及独立冷备恢复。原生 CE／Edge 组合使用 aarch64 Docker 主机运行 linux/amd64 镜像，记录架构模拟、峰值资源、退出和 OOM；Edge 使用 Java PID1 与六十秒停止宽限，已核对实际停止及配套原数据再次启动。

## 平台与待执行专项

正式自动构建目标为 Linux amd64，完整生成器采用 Linux x86_64 Compose；本机演示支持按构建器生成的 linux／darwin 和 amd64／arm64 程序。UOS Server V20 x86_64 作为目标部署环境继续执行专项。

完整 UOS 安装与恢复、单节点及三节点连续断云 24 小时、受限链路补传补算、实际 24 小时容量和持续运行测量属于目标环境专项，按[安装](../installation.md)、[备份恢复](../operations/backup-restore.md)及对应检查工具准备并记录结果。

GitHub 每次运行执行的自动步骤和产物见[构建指南](../development/build.md)，版本标签重新记录应用版本和源码清单；发布操作前按[消息升级](../消息组件升级.md)与数据库恢复条件准备配套备份。
